# 🚀 Quick Start Guide - ResearchNet

## **Step 1: Start the Application**

```bash
cd /home/kishlay/per/frontend
npm run dev
```

Open: `http://localhost:5173`

---

## **Step 2: First Time User Experience**

### **1. Register/Login**
- Go to `http://localhost:5173/login`
- Click "Sign Up" tab
- Fill form with password like "Password123" (needs uppercase, lowercase, number)
- Click "Create Account"

### **2. Dashboard Overview**
- You'll see your dashboard with statistics
- Quick action buttons for main features
- Welcome message with your name

---

## **Step 3: Explore All Features**

### **📊 Dashboard** (`/dashboard`)
- Your main hub
- Statistics and quick actions
- Recent activity feed

### **📱 Social Feed** (`/feed`)
- See posts and papers from your network
- Like, comment, and share content
- Filter by type (all, papers, posts)

### **📚 Browse Papers** (`/papers`)
- Search and filter research papers
- Click any paper to view details
- Sort by date, citations, downloads

### **📄 Paper Details** (`/paper/1`)
- Full paper content
- Like, bookmark, share, comment
- View statistics and related papers

### **👥 Network** (`/network`)
- Connect with researchers
- View suggestions
- Manage your connections

### **✍️ Create Posts** (`/create-post`)
- Share updates, papers, or collaboration requests
- Add tags and attachments
- Set visibility preferences

### **📝 Publish Papers** (`/publish`)
- Comprehensive paper submission form
- Add authors, methodology, results
- Upload PDF and submit for review

### **👤 Profile** (`/profile`)
- Update personal and professional information
- Add research interests and affiliations
- Manage online presence

---
