# 🎉 Complete User Experience - ResearchNet

## **🚀 How to Access All Features After Sign-In**

### **Step 1: Start the Application**
```bash
cd /home/kishlay/per/frontend
npm run dev
```
**Open:** `http://localhost:5173`

### **Step 2: Sign In Successfully**
- Go to `http://localhost:5173/login`
- Use email/password or Google OAuth
- You'll be redirected to Dashboard

## **🎯 Where to Click for Each Feature**

### **📊 Dashboard** (Main Hub)
**Click:** "Dashboard" in top bar or "ResearchNet" logo
**What You Get:** Overview, statistics, quick actions, getting started guide

### **📱 Social Feed** (`/feed`)
**Click:** "Feed" in top bar OR "Social Feed" card on Dashboard
**What You Can Do:**
- See posts and papers from your network
- Like, comment, and share content
- Filter by All Activity, Papers, or Posts
- Create new posts

### **📚 Browse Papers** (`/papers`)
**Click:** "Papers" in top bar OR "Browse Research" card on Dashboard
**What You Can Do:**
- Search papers by title, author, keywords
- Filter by category (Computer Science, Physics, etc.)
- Sort by date, citations, downloads
- Click any paper to view details

### **📄 Paper Details** (`/paper/1`)
**Click:** Any paper card from Papers page
**What You Can Do:**
- Read complete paper content
- Like, bookmark, share, comment
- View author profiles
- Download PDF (simulated)
- See related papers

### **👥 Research Network** (`/network`)
**Click:** "Network" in top bar OR "Research Network" card on Dashboard
**What You Can Do:**
- View your current connections
- See suggested researchers
- Connect/disconnect with researchers
- View detailed researcher profiles
- Track network statistics

### **✍️ Create Posts** (`/create-post`)
**Click:** "Share Update" button from Feed page
**What You Can Do:**
- Create general posts
- Share research papers
- Request collaborations
- Add tags and attachments
- Set visibility preferences

### **📝 Publish Papers** (`/publish`)
**Click:** "Publish" in top bar OR "Start Publishing" card on Dashboard
**What You Can Do:**
- Fill comprehensive paper submission form
- Add multiple authors with affiliations
- Include methodology, results, conclusion
- Upload PDF and submit for review
- Track submission status

### **👤 Profile Management** (`/profile`)
**Click:** "Profile" in top bar OR "Your Profile" card on Dashboard
**What You Can Do:**
- Update personal information
- Add professional details
- Include research interests
- Manage online presence
- Update education and experience
