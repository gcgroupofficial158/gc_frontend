# 🎯 Complete Feature Access Guide

## **How to See All Changes & Features**

### **1. Start the Application**
```bash
cd /home/kishlay/per/frontend
npm run dev
```
**Open:** `http://localhost:5173`

---

## **2. Complete User Journey**

### **Step 1: Authentication**
**URL:** `http://localhost:5173/login`

**Options:**
- **Email/Password**: Register with strong password (e.g., "Password123")
- **Google OAuth**: One-click Google sign-in

**After Login:** Automatically redirected to Dashboard

---

### **Step 2: Dashboard Experience**
**URL:** `http://localhost:5173/dashboard`

**What You'll See:**
- Welcome message with your name
- Statistics cards (Papers, Reviews, Connections, Citations)
- Quick action buttons
- Recent activity feed

**Quick Actions:**
- "Start Publishing" → Go to paper publishing
- "Browse Papers" → Go to papers page

---

### **Step 3: Explore All Features**

#### **📱 Social Feed** 
**URL:** `http://localhost:5173/feed`
- See posts and papers from your network
- Like, comment, and share content
- Filter by type (All, Papers, Posts)
- Click "Share Update" to create posts

#### **📚 Browse Papers**
**URL:** `http://localhost:5173/papers`
- Search papers by title, author, keywords
- Filter by category (Computer Science, Physics, etc.)
- Sort by date, citations, downloads
- Click any paper card to view details

#### **📄 Paper Details**
**URL:** `http://localhost:5173/paper/1` (or any ID)
- Complete paper content with all sections
- Like, bookmark, share, comment
- View statistics and related papers
- Full commenting system with replies

#### **👥 Research Network**
**URL:** `http://localhost:5173/network`
- View your current connections
- See suggested researchers
- Connect/disconnect with researchers
- View detailed researcher profiles

#### **✍️ Create Posts**
**URL:** `http://localhost:5173/create-post`
- Share general updates
- Discuss research papers
- Request collaborations
- Add tags and attachments

#### **📝 Publish Papers**
**URL:** `http://localhost:5173/publish`
- Comprehensive paper submission form
- Add multiple authors
- Include methodology, results, conclusion
- Upload PDF and submit for review

#### **👤 Profile Management**
**URL:** `http://localhost:5173/profile`
- Update personal information
- Add professional details
- Include research interests
- Manage online presence
